# Terminally Agentic A/V

An in-progress project for a reusable creative recipe and tools for making audio-visual band worlds.

## Public scope

This repository is for reusable process and tooling. Individual band identities, albums, recordings, visuals, and their production materials are kept outside this project.

## Roadmap

1. Complete the planned 16-album sequence.
2. Build a universal web viewer.
3. Develop terminal-friendly visual interpretations.
4. Build a CLI around those interpretations.
5. Publish the refined reusable recipe and tooling.

See [PROJECT-ROADMAP.md](PROJECT-ROADMAP.md) for the fuller sequence, play-along direction, and contribution policy.

## Release status

The software and media licenses have not been selected. This repository currently contains planning documentation; album media and production assets are not included.
